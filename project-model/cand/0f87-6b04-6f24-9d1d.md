# Cross-language keyword boost: add the English equivalents of a query's GIS terms, taken from cleared gis-glossary sources, to the lexical part of hybrid search

Additive only: the user's words are kept, equivalents get a lower weight, nothing is added when no term matches or language confidence is low (today's behaviour). The term table ships as a separate data file under its own licence (CC BY-SA if the Árni Magnússon dictionaries are included), next to the MIT code. Built from an allow-list of glossary source_ids: cleared sources only; LÍSA, ISO/TC 211 MLGT and the Geonorge code lists join when their holders agree. A local build with every source measures what each pending source would add. The glossary's acceptance test found most of the Norwegian gain in the keyword part.
