# Keep the legacy potion-base-8M data set (index.json) for released versions up to 0.4.8, and publish the multilingual one beside it with an ml suffix (index-ml.json, EmbeddingModel-ml, Embeddings-ml-<u>), which the new plugin version reads

Merging the multilingual model must not switch installed 0.4.8 plugins silently: they keep potion until their users update. One BuildEmbeddings run fetches the catalogue and readmes once and builds both data sets; StoreEmbeddings --variant ml writes the ml files, and a run of one data set only ever deletes its own files (ownsFile). Readme caches are shared. The plugin's default index becomes index-ml.json (Settings.INDEX_NAME). Release order: merge, run BuildEmbeddings once by hand so index-ml.json exists, then publish the plugin. The legacy data set can be dropped once no supported version reads index.json.
