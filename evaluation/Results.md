## 1. English: sentence against keyword list

Each task need is asked as a sentence and as the keyword list a keyword search user would type, both written by claude-haiku-5-5 (medium effort) from the task alone (evaluation/QueryPrompt.txt), blind to the catalogue. Both forms run on every backend: a keyword list can be typed into the semantic search box too. `author` rows are the evaluation author's own wording, kept for comparison. Judgments are per need, so every form is judged against the same expected plugins. `found@10`: a plugin that does the task is on the first screen; `precision@10`: share of the first screen (or of the whole list when shorter) that is relevant.
